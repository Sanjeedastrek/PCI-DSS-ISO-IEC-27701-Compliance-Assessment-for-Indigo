# PCI-DSS-ISO-IEC-27701-Compliance-Assessment-for-Indigo
This project applies PCI DSS and ISO/IEC 27701 controls to a cloud-based campaign environment through risk assessment, data flow analysis, and practical compliance implementation.

The project focuses on practical decision-making rather than theoretical compliance. Particular attention is given to:
  - outsourced payment processing
  - participant data handling
  - cloud-based campaign infrastructure
  - third-party vendor dependencies
  - operational privacy controls

Built as a presentation-style walkthrough to simulate how a junior security analyst might approach compliance analysis in a real campaign environment.
